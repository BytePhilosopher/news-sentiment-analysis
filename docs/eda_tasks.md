# Exploratory Data Analysis (EDA) Tasks for News Sentiment Analysis

## 1. Data Understanding
- Load the raw datasets from the `data/raw` directory.
- Examine the structure and content of the datasets.
- Identify the target variable for sentiment analysis.

## 2. Data Cleaning
- Remove duplicates and irrelevant entries from the datasets.
- Handle missing values appropriately (e.g., imputation or removal).
- Normalize text data (e.g., lowercasing, removing punctuation).

## 3. Text Preprocessing
- Tokenize the text data to convert sentences into words.
- Remove stop words to focus on significant words.
- Apply stemming or lemmatization to reduce words to their base forms.

## 4. Exploratory Analysis
- Generate descriptive statistics (e.g., word counts, sentence lengths).
- Visualize the distribution of sentiments using bar charts or pie charts.
- Analyze keyword frequencies and trends over time.

## 5. Feature Extraction
- Implement techniques such as TF-IDF and CountVectorizer to convert text data into numerical features.
- Explore the impact of different feature extraction methods on model performance.

## 6. Correlation Analysis
- Investigate correlations between features and the target variable.
- Use visualizations (e.g., heatmaps) to identify significant relationships.

## 7. Documentation
- Document findings and insights from the exploratory analysis.
- Prepare visualizations and summaries for inclusion in the final report or presentation.
